# 使用说明

## 环境

- Windows 10/11
- .NET 10 桌面运行时（或使用自包含发布）
- 不需要 iTunes、不需要越狱工具链；程序不访问设备

## 第一次使用

1. 启动程序，等资料库加载完成（首次为空）
2. 顶部页签是源（首次启动已内置若干可用源）；点「抓取索引」把源里的包索引拉到本地
   - 「全部」页签的「抓取索引」= 依次抓所有启用的源
3. 在中间「源浏览器」里搜索/浏览包；可在右上角按 iOS 版本过滤
4. 选中一个或多个包 → 点「算闭包」（或右键「算闭包」）
5. 闭包窗口里会列出：要下载的包 / 已满足的依赖 / 未解析项（含原因）
6. 二选一：
   - 「下载到资料库」：只下载进本地 pool（不复制到目录），之后在资料库右键分组再导出
   - 「导出到…」：下载并直接导出到目录
7. 把导出的目录内容拷到设备，放进 `/var/root/Media/Cydia/AutoInstall`（或对应路径），重启设备即可安装

> AutoInstall 由系统启动后的 launchd 作业处理；安装顺序由 dpkg 自己按依赖排，文件名前缀只是便于人工核对。

## 常用操作

- **换源**：右键源页签 → 编辑/删除；工具条「源」菜单同样入口；可添加自定义源（名称可留空自动生成，地址缺协议自动补 `http://`）
- **目标设备**：设置 → 目标设备 → 选内置机型（或手改任意字段）。目标设备决定伪包取值，从而决定哪些包"装得上"
- **资料库分组**：一次下载/导出 = 一个分组（根插件 + 整个依赖闭包）；同名插件多次记录可合并显示
- **自定义分组**：资料库顶部「分组」下拉 + 新建/重命名/删除；右键「加入分组」「从当前分组移出」
- **导出**：资料库右键「导出这一组 / 导出这个 deb」；导出**只复制**，不删不改你目录里的文件
- **清理**：「清理已移除」删除已不在任何分组里的 pool 文件与台账行；「修复缺失」把台账有、磁盘没有的包重新下载回来
- **并行下载**：设置 → 网络 → 同时下载（默认 4，可调 1–8）与单源上限

## 命令行自检（可选）

```powershell
# 抓索引（并落库）
CyDownload.Probe fetch archive\archive.db

# 对已有库算闭包
CyDownload.Probe resolve archive\archive.db wget

# 算闭包并导出
CyDownload.Probe export archive\archive.db .\out wget

# 修复"台账有、磁盘没有"的 pool 对象
CyDownload.Probe repair archive\archive.db
```

## 数据放在哪里

都在程序目录下：`archive\archive.db`、`archive\settings.json`、`archive\pool\objects\`、`archive\groups.json`、`logs\`。
程序目录不可写会直接提示，不会写到用户目录。

## 限制

- 只归档索引里存在、且源仍可访问的包；源关站后无法补齐
- 不支持断点续传（部分老源 Range 实现不可靠）
- 目标 iOS 版本不满足伪包约束（如 `firmware (>= 7.0)`）时，该包会被判为不可装，这是预期行为
